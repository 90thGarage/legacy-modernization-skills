# 90thSkills Next Sandbox

This is a disposable but clean Next.js target for testing `90thSkills`.

## Included

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- shadcn/ui initialized with Radix components
- Common shadcn components used by legacy modernization flows

## Test Prompt

```txt
Use /builder.

Input handoff:
docs/ux/<view-name>-ui-handoff.md

Destination:
skill-flow-test/next-sandbox/src/features/<view-name>/

Also add a route at:
skill-flow-test/next-sandbox/src/app/<view-name>/page.tsx
```

## Local Commands

```bash
npm install
npm run dev
npm run lint
npm run build
```
