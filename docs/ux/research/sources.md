## Evidence Tags

- `demo-confirmed`: explicado funcionalmente en la demo/minuta.
- `demo-inferred`: inferido desde la demo, pero no expresado como regla cerrada.
- `needs-user-validation`: requiere validacion con cajeros, administrativos, duenos u otros usuarios operativos.
- `open-question`: falta una respuesta de producto o dominio.
- `future-scope`: existe o se espera en IM5/IM4, pero no esta suficientemente cubierto para redisenar ahora.

## Update Rule

Cuando entre una nueva minuta, actualizar el contexto sin pisar silenciosamente decisiones previas. Si aparece una contradiccion, agregarla como pregunta abierta o decision pendiente de resolucion.
