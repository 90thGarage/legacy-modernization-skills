# Assets

Place client assets here so `builder` can reference them from `references/design.md`.

Suggested structure:

```txt
assets/
  logos/
  icons/
  brand/
  screenshots/
```

Do not rely on assets being discovered automatically. Reference important files explicitly in `design.md`.

## Available Assets
